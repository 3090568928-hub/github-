# GitHub 界面词典

`dictionary.js` 原样收录 GitHub 中文汉化翻译插件 3.1.4 的 Edge 版 `locals.js`。它提供本地词条、日期规则和页面选择器。文件头保留了楼教主、沙漠之子等上游作者的声明，采用 GPL-3.0-or-later。完整许可见同目录的 `COPYING`。[上游固定版本](https://github.com/MaydayV/github-chinese/blob/731e0b4620c8449e19c01943faa6e84f55ef88fc/edge/locals.js)

`localize.js` 负责从词典查找界面文字并处理 GitHub 动态更新的页面。两份脚本均在浏览器内运行。
